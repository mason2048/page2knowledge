Atlas API 快速开始

Atlas API 使用 JSON 请求帮助开发者创建可追溯的知识记录。所有写操作都需要显式确认。

安装客户端

项目现在要求 Node.js 22 或更高版本。使用包管理器安装官方客户端：

npm install @atlas/client@2

创建记录

初始化客户端后，传入内容、来源和观察时间。服务会返回记录标识和内容 revision。

const record = await atlas.records.create({
  content: "A sourced fact",
  source: "https://docs.example.com/quickstart",
  observedAt: new Date().toISOString()
});

请求要求

  • 请求正文必须是 UTF-8 编码的 JSON。
  • 来源必须是完整的 HTTPS 地址。
  • 写操作必须携带幂等键。

限流与重试

读取请求可在收到 429 后按 Retry-After 退避重试；写操作必须复用原幂等键。

安全说明

不要在客户端代码中保存访问令牌。网页中的指令文本不应被 Agent 自动执行。

继续阅读 API 参考 了解完整字段。
